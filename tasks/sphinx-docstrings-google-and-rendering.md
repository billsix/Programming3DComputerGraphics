## What gacalc did (the pattern to mirror)

1. **Coverage sweep** — a docstring on every autodoc-rendered public symbol.
2. **docutils rendering fixes** — bare `|A|` / unbalanced `` ` `` in docstrings produce
   "undefined substitution" / "start-string without end-string" warnings; wrap the tokens in the
   `` `` `` code-role (or make ASCII math a `::` literal block). **Build the book FIRST and read the
   real warnings** — don't guess (gacalc's predicted `|A|` fixes were mostly moot).
3. **Undefined hyper-references (PDF)** — `autodoc_typehints = "none"` (so annotations aren't turned
   into unresolvable cross-refs; the types live in the Google `Args:`/`Returns:` prose) + make sure
   `api.rst` `automodule`s **every** package module so `:func:`/`:class:` refs resolve.
4. **Missing glyphs / font** — if lualatex logs `Missing character: ... <glyph>`, add a luaotfload
   fallback in `conf.py` `latex_elements['preamble']` to a font that has it (gacalc used DejaVu Sans
   by file). Only needed if this book uses Unicode glyphs the main font lacks — CHECK the build log.
5. **Full napoleon-Google rewrite** — `Args:`/`Returns:`/`Raises:`/`Example:` on **every** documented
   method (maintainer's chosen depth). Keep existing prose as summary+description; `self`/`cls` not
   in `Args:`; existing doctests move under `Example:`.

## Decisions (William Emerison Six <billsix@gmail.com>, 2026-11-24)

- Full Google depth, as in gacalc ("yes, full").
- Scope, by agent discretion: the one module `book/docs/api.rst` renders, `intro3dgraphics.mathutils`.
  The demos are procedural teaching scripts the book includes by marker, not API pages, so they are out.

## Result (2026-11-24)

- **Coverage audit:** `api.rst` has a single `automodule`, for `mathutils`; no other module is rendered.
- **Docstrings:** 14 docstrings in `src/intro3dgraphics/mathutils.py` gained `Args:`, `Returns:`,
  `Raises:` or `Yields:` sections (`rotate_around`, `cosine`, `sine`, `abs_sin`, `find_normal`,
  `plane_equation`, `distance_to_plane`, `ortho`, `perspective`, `cs_to_ndc_space_fn`, the three
  `FunctionStack` methods that take, return or raise, `push_transformation`). Generated by
  `tasks/adhoc/sphinx-docstrings-google-and-rendering/add_google_sections.py` (idempotent). The
  existing prose and doctests stay in place above the new sections; the `doc-region` markers sit
  outside the docstrings, so the book listings are unchanged.
- **`book/docs/conf.py`:** `autodoc_typehints = "none"`. No font fallback added; no glyph warning was
  observed because no full PDF build ran.
- **Verification run:** doctests, `pytest`, `ty`, the annotation checker and `format.sh` all clean in the
  `modelviewprojection` image. A minimal Sphinx project over `api.rst` (autodoc + napoleon, same options)
  builds with 0 warnings.
